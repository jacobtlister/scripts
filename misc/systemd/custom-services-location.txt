sourced the spectacle systemd service from the forum post below:
    https://discuss.kde.org/t/make-spectacle-launch-faster/38030/6

put the spectacle.service file in:
    $HOME/.config/systemd/user/

to start spectacle.service if you have not done so before, run the following commands:
    systemctl --user daemon-reload
    systemctl --user enable --now spectacle.service

first, reload the user services of systemctl. then, you enable your custom service (causes it to start up whenever you login) and also
start the service immediately (using --now)
